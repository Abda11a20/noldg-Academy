# Noldg Academy Frontend

Frontend foundation workspace for the Arabic first tutoring platform.

## Requirements

- Node.js 24 LTS (`.nvmrc`)
- pnpm 11 (`packageManager` in the root manifest)

## Development

Install dependencies with `pnpm install`, then run `pnpm dev` for the portal. Use `VITE_API_MODE=mock` for the mock API or `VITE_API_MODE=live` with `VITE_API_BASE_URL` for a backend. Run `pnpm test`, `pnpm lint`, `pnpm typecheck`, and `pnpm build` for verification.

The workspace is still being initialized; scripts become usable as the F0 foundation lands.
